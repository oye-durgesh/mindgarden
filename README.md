# MindGarden

A calm-focused brain gym: daily games, breathing, mood check-ins, and a plant that grows with your streak.

## Stack

React + Vite, Tailwind CSS, Framer Motion, React Router. All data lives in `localStorage`.

## Local

```bash
npm install
npm run dev
```

## Build / Render

```bash
npm run build
```

Deploy as a Render Static Site. Publish directory: `dist`. No environment variables required.
